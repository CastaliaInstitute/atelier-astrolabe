# Chakra yantra sources

PNG previews are downloaded from [Wikimedia Commons](https://commons.wikimedia.org/wiki/Category:Chakras) by `scripts/embed_chakra_glyphs.py` and converted to embedded alpha masks in firmware.

Attribution: yantra diagrams such as Muladhara.svg by Mirzolot2 and related Commons uploads (CC BY-SA 3.0). Regenerate with:

```bash
python3 scripts/embed_chakra_glyphs.py
```
