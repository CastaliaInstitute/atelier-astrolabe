# Psychometer Ritual

The Psychometer is a small instrument for noticing an internal state. It does
not diagnose, score, correct, or optimize the person using it.

## Daily sequence

### 1. Arrive

The device wakes to the user's personalized neutral Memoji face. It uses a
slow pulse and a brief blink as an invitation, not an alarm. There is no streak,
deadline, or missed-check-in language.

### 2. Make the face familiar

The user may rotate through their appearance settings before recording a state:

- skin tone
- hair
- eyes
- nose
- facial hair
- glasses

These are identity features, not mood controls. They remain unchanged between
check-ins unless the user deliberately edits them.

### 3. Set arousal

The user rotates the dial to answer: **How activated is my body right now?**

The scale runs from low to high: sleepy or withdrawn, calm, alert, energized,
restless, or tense. The scale is continuous, and the center is not treated as a
default or ideal.

### 4. Set valence

The user rotates the dial to answer: **How does this state feel from the inside?**

The scale runs from unpleasant to pleasant, with neutral and mixed states
available in the middle. The device never labels a state as good or bad.

### 5. Confirm

The user presses the dial or taps the face to record the reading. The face holds
the selected expression for several seconds and acknowledges it with a blink,
breath, or small glow. This is witnessing, not approval.

### 6. Share with Astrolabe

The Psychometer sends the reading over ESP-NOW to the paired Astrolabe. The
Astrolabe accepts it only from a known pairing identity and returns a short
acknowledgment. The Psychometer shows connection status without exposing another
person's identity or state.

### 7. Return

After acknowledgment, the device returns to the personalized neutral face. It
does not offer advice or ask the user to change their state.

## Ritual modes

- **Morning**: What state am I carrying into the day?
- **Evening**: What state remained with me?
- **In the moment**: Something changed.

The mode is metadata attached to the reading, not a separate emotional scale.

## Astrolabe response

The Astrolabe Psychometer face presents the latest paired reading as a Memoji
portrait with a restrained arousal/valence expression. The reading may inform
personal readings and family synastry only where the user has opted in.

The response should be symbolic rather than diagnostic: a constellation shift,
orbit change, or gentle received animation. It must not display a wellness
score, prediction, warning, or corrective prescription.

## Design principle

**The Psychometer does not measure the person. It gives the person a small,
physical language for noticing themselves.**
