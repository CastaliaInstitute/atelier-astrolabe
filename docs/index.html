Reference hardware

Built on the Waveshare ESP32-S3 Touch AMOLED 1.75C class board — open toolchain, open firmware.

Display ~1.75″ round AMOLED, 466×466, capacitive touch
MCU ESP32-S3 (Wi‑Fi + BLE), PSRAM for voice buffers
Audio Onboard mic array; ES8311 speaker path for MP3 playback
Connectivity Wi‑Fi + NTP; Castalia Supabase edge functions
Power USB-C; battery-friendly sleep between interactions
Software PlatformIO / Arduino; MIT vendor audio stack + minimp3

Questions

Do I need a Mynah phone?

No. Astrolabe talks to Castalia’s cloud on its own. Mynah Android is the reference companion today; BLE/LAN presence with home Mynah is on the Phase 3 roadmap.

Is V0 a dev kit or a finished product?

V0 is a real wearable with production-intent UX, but ephemeris accuracy will improve as Castalia’s server-side Swiss Ephemeris lands. Founders get firmware updates as faces mature.

Can I build my own?

Yes. Firmware and build instructions live in the astrolabe repository. V0 purchases support continued development and bench QA.

When does it ship?

V0 ships in small waves through 2026. Waitlist order is first-confirmed, first-built; we’ll reply with your window after reservation.
