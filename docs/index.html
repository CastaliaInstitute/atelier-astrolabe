Faculty-guided design

Built to protect attention, not harvest it.

Inquirer Volume IV gives Astrolabe a stricter product rule: AI may assist, retrieve, rehearse, and remember, but the watch must preserve human judgment, source trails, protected silence, and real-world handoff.

Thresholds

Know the mode

Local, cloud, faculty, journal, and shared states should be visible before the user crosses them.

Provenance

Trace the answer

Generated replies, readings, and summaries should keep compact source, route, prompt, and human-action records.

Recollection

Let silence count

Rest, reading, studio, sabbath, and seminar blocks reduce prompts and treat non-use as successful use.

Handoff

Return outward

The best flow often ends in a saved note, a source card, a conversation, a class, a meal, prayer, or sleep.

Common architecture

Voice. Memory. Presence.

All Astrolabe devices share a unified round module and magnetic dock integration. The shell changes the rhythm; the core hardware and firmware lineage stay familiar.

Module

1.75-inch round AMOLED, USB-C charging and data, Wi-Fi, BLE, and offline-capable firmware.

Sensors

Temperature, heart-rate/PPG, respiration, accelerometer, ambient light, sound, and pressure pathways.

Docking

Magnetic alignment, secure hold, charging display, and keyed orientation for accessory shells.

Interface

Touch, side buttons, speaker, microphone, and I2C expansion for mount and electrode accessories.

Variant feature matrix

Hardware capabilities and face families by release.

Each release pairs a device platform with a firmware variant, NVS identity, OTA channel, hardware capability set, and default face family.
