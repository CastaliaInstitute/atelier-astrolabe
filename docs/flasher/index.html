Local mode writes the selected file at the app address above. Use this for test builds or recovery images when they already match the device partition layout.

Before flashing

  • Use Chrome or Edge on a secure origin.
  • Select the USB Serial/JTAG port for the attached Astrolabe.
  • If connect fails, hold BOOT while plugging in, then try again.
  • The default mode flashes only the app image at 0x10000.

Full factory flashing also needs bootloader and partition images. Release manifests include those artifacts when the build publisher has them.
