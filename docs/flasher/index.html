Before flashing

  • On Android, use Chrome and connect Astrolabe through USB-C/OTG.
  • For a local build, keep the CLI flash bridge running until flashing finishes.
  • Select the USB Serial/JTAG port for the attached Astrolabe.
  • If connect fails, hold BOOT while plugging in, then try again.
  • Local CLI builds include the bootloader, partitions, OTA data, and app image.

Full factory flashing also needs bootloader and partition images. Release manifests include those artifacts when the build publisher has them. If the device boots to ROM after a full-layout flash, retry with "Include bootloader, partition table..." unchecked.
